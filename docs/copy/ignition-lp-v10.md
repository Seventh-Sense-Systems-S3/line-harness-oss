## なぜこれが効くか (脳科学レベル)

### 1. **記憶活性 (Memory Activation)**
読者は YouTube/Instagram/TikTok の波を **既に体験している**。脳の海馬から自分の体験記憶が引っ張り出される。これがLPの主張に **個人的事実の重み** を与える。

### 2. **後悔回避 (Regret Avoidance)**
「あの時 始めておけば」という後悔は、誰もが経験している人類普遍の感情。それを思い出させた上で「今が、その時だ」と告げる構造は **後悔を未然に回避したい衝動** を最大化する。

### 3. **時間の心理的距離 (Construal Level Theory)**
- 3年後 = 抽象的、自分事じゃない、対岸の火事
- 半年後 = 具体的、目の前、すぐ予測可能

「半年後」は読者の脳が **すぐ動かせる範囲** として認識する。

### 4. **格差の絶対値 (Absolute Gap Framing)**
レベル10 vs レベル0 という **追いつき不可能性** が、Loss Aversion を爆発的に増幅する。「同レベル」だと「まあ後でもいいか」になるが、「絶望的格差」は **今動かないと永久に追いつけない** 緊迫感を生む。

### 5. **3連反復のリズム (Tricolon Effect)**
「毎日 / 毎日 / 毎日」の三連は、シーザーの "Veni, Vidi, Vici" と同じ修辞技法。脳に深く刻まれる。
