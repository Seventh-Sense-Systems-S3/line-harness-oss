## 🆕 V12 ⑤b NEW: 失敗者の影 (Loss Aversion)

⑤ Why now? と ⑥ After の間に挿入：

```
[ Dark muted section / 中央寄せ / 余白多め ]


少し、別の話をしよう。


3年前、まだ "分身AI" という言葉がなかった頃、
子竜のチャレンジには、
さまざまな人が 集まってきた。

そして、その中で──
"参加したのに、行動しなかった" 人たち も いる。

彼らの今を、想像してみてほしい。


      ──いまも、ChatGPTで下書きを書き、
      ──いまも、「私らしさが出ない」と 唸り、
      ──いまも、半年前の投稿を、読み返したくない。


  3年経って、
  同じ場所で、
  同じ問いに、
  止まったままだ。


これが、波に 乗らなかった人の 静かな代償だ。


  ──そして、波は、待ってくれない。
```

> **設計意図**:
> - 個人特定の捏造を避け、「失敗者の集合像」として描く
> - 「いまも〜」3連で時間停止感を強烈に演出 (Tricolon)
> - "静かな代償" = 派手な失敗じゃなく日常的停滞 = ターゲットの実感に近い
> - Loss Aversion (Kahneman) を最大化

## 🆕 V12 ⑤c NEW: アイデンティティスタンプ (Embodied Simulation)

⑤b 失敗者の影 と ⑥ After の間に挿入：

```
[ Hero-style large block / 中央寄せ ]


あなたは、いま──

スマホを 手に持っている。
画面の光が、目に届いている。
親指の先が、画面に 触れている。


そして、ここまで 読んだ。


  ──これは、偶然じゃない。


あなたが、ここまで読んでいる ということは、
あなたの 中の何かが、
この言葉に 反応している ということだ。


  「もっと、できるはずなのに」
  「自分の核を、形にしたい」
  「3年後、こうじゃない 自分でいたい」


その声が、まだ 残っている人だけが、
ここまで 読み進めている。


だから 言える。


  ──あなたは、運ばれてきた人だ。


  この言葉に。 この場所に。
  そして、この3日間に。
```

> **設計意図**:
> - **二人称現在形 + 身体感覚** で Embodied Simulation 発動 (Williams & Bargh)
> - 「スマホを手に持っている / 画面の光 / 親指の先」 = 触覚・視覚・固有感覚を一気に活性化
> - 「運ばれてきた人だ」 = セラピスト/カウンセラー層の運命的フレーミング
> - 観察モード → 主人公モード への臨界点
> - Default Mode Network → Salience Network への切替
